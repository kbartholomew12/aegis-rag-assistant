HOW AEGIS WORKS

Generation is the last step, not the first.

Aegis separates knowledge retrieval, governance decisions, and language generation so the LLM is not responsible for making the highest-risk policy choices.

1

Retrieve

Search only the curated fictional policy library for relevant passages.

2

Guard

Check knowledge boundaries, scenario type, policy hierarchy, and escalation rules.

3

Ground

Send only the selected policy passages and scenario context to Claude.

4

Generate

Claude synthesizes concise guidance from the retrieved sources rather than open-ended model knowledge.

5

Verify

Show the primary and supporting sources and keep professional judgment in the loop.

Portfolio architecture: FastAPI/Python backend · local policy knowledge base · TF-IDF retrieval with scenario-aware reranking · deterministic governance guardrails · Claude API grounded synthesis · source transparency.
01

Bounded knowledge

Questions outside the AI-governance library are refused instead of matched to unrelated policies.

02

Policy hierarchy

Controlling passages are marked as primary; supporting sources add restrictions or context.

03

Escalation by design

Incident response and high-risk situations prioritize human action rather than generic guidance.
